# Boss Studio 4.9 — трофеи и ручная выдача мемкоинов

Распакуй архив, запусти `ЗАПУСТИТЬ BOSS STUDIO.bat`, открой `http://127.0.0.1:8765/easy`. В OBS добавь браузерный источник `http://127.0.0.1:8765/live/overlay.html?easy=1` размером 3000×3000.

## Заявки зрителей

После победы каждый участник боя получает трофей и одну запись о награде в размере, указанном у босса. Участие через урон, щит и боевые бонусы учитывается. Тестовый бой не создаёт заявок. Когда собраны трофеи всех включённых боссов, зритель на странице наград подтверждает Twitch одноразовой командой `!профиль КОД`, вводит свой ник MemeAlerts и нажимает «Получить награду». Все ещё не запрошенные награды этого Twitch ID объединяются в одну заявку. Ник MemeAlerts вводится самим зрителем и автоматически сайтом не проверяется.

В управлении эфиром появится «Ожидает награды» с Twitch именем, ником MemeAlerts и суммой. Нажми «Открыть выдачу мемкоинов», найди зрителя на MemeAlerts, выдай мемкоины там вручную и только после этого нажми «Отметить выданным» в Boss Studio. Эта кнопка отмечает локальную запись; она не отправляет монеты. Для новой победы зритель может подать новую заявку при полной коллекции. Список с никами скрыт по умолчанию.

## Настройка страницы

1. В редакторе на вкладке «Трофеи» нажми «▶ Проверить страницу зрителя»: локальная демо-страница показывает условно собранные трофеи и результат нажатия кнопки без изменения реальных данных.
2. Для настоящих зрителей настрой HTTPS-туннель только к `127.0.0.1:8766`, сохраняя исходный заголовок Host. Не выставляй административный порт `8765` наружу. Встроенного туннеля нет.
3. Введи публичный HTTPS-адрес в редакторе и сохрани. Настрой Streamer.bot WebSocket на `127.0.0.1:8080` и Twitch; если для WebSocket включён пароль, впиши его в соседнее поле. При победе программа отправит ссылку `/claim` в Twitch-чат. Команда `!профиль КОД` должна прийти через подключённый Streamer.bot.
4. Нажми «↗ Открыть страницу зрителя» для проверки опубликованных трофеев. Настоящая заявка создаётся только после подтверждения Twitch и полной коллекции. Порт `8766` содержит только страницу и API зрителя; управление заявками доступно лишь в локальном интерфейсе `8765`.

Публичный адрес, пароль и ссылка для чата скрыты по умолчанию; глазик показывает поле, ⧉ копирует полное значение и при скрытом поле. Ники ожидающих награды видны только после кнопки «Показать заявки» в локальном управлении эфиром. Демо-режим работает лишь на локальном адресе и ничего не записывает.

Для ручной выдачи регистрация API-приложения MemeAlerts не нужна. В старых установках `meme-auth.json` остаётся на компьютере как прежний файл, но программа больше не использует его Client Secret и токены; публичный адрес и пароль Streamer.bot однократно переносятся в `viewer-config.json`. Ранее начатые и неоднозначные отправки требуют сверки баланса вручную. Исторические локальные предметы и балансы архивируются отдельно.

Опубликованный набор боссов и трофеев читается страницей зрителя из текущего конфига эфира. После изменения названия, PNG или состава боссов нажми «Применить выбранных боссов в эфире»; страница обновится в течение пяти секунд. В «Расписании» настраиваются первый босс, интервалы, лимит и очередь конкретных или случайных боссов.
