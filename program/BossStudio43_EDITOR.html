Реакции на Twitch

Задай величину урона за действия зрителей. Донаты поступают от внешнего сервиса по отдельному триггеру — в тестовом режиме сумму можно задавать вручную.

🏆 Трофеи боссов

По одному трофею на каждого босса. Зритель сможет запросить награду, когда соберёт по одному трофею каждого включённого босса. Размер выплаты за каждую победу задаётся ниже.

Заявки и ручная выдача MemeAlerts

Зритель подтверждает Twitch в чате, собирает трофеи и указывает свой ник MemeAlerts. Заявка появляется в управлении эфиром. Открой страницу выдачи на MemeAlerts, найди зрителя и выдай указанную сумму вручную; затем отметь заявку выданной в Boss Studio. Регистрация приложения не нужна.

Для синхронизации нужна запущенная программа Streamer.bot с WebSocket-сервером.

Выгрузка выбранных боссов

Отмечай боссов во вкладке «Сохранение и экспорт». При выгрузке будут перенесены только отмеченные PNG/GIF; вся остальная база редактора сохраняется.

Первая синхронизация доступна после запуска локального моста.

📘 Развернуть полную инструкцию подключения Streamer.bot и OBS

1. Запусти локальный мост

Из распакованной папки Boss Studio запусти «ЗАПУСТИТЬ BOSS STUDIO.bat». При первом запуске необходимые компоненты будут подготовлены автоматически. Открой адрес http://127.0.0.1:8765/editor. Не открывай редактор двойным кликом по HTML для синхронизации: используйте адрес моста.

2. Подключение без C#

Включи Twitch в Streamer.bot, а затем его WebSocket Server: адрес 127.0.0.1, порт 8080 и Start. Вернись в окно «Простой запуск» и проверь подключение.

3. Обновление боссов

Выбери нужных боссов, нажми «Синхронизировать сейчас». Потом вернись к простому запуску и нажми «Запустить босса».

4. OBS

Добавь источник «Браузер»: http://127.0.0.1:8765/live/overlay.html?easy=1. Поставь размеры 1920 × 1080.

Если ранее был старый Action, отключи его Twitch-триггеры во избежание дублей.
