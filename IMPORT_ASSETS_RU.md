# Загрузка оригинальной графики Boss Studio 4.9

В репозитории опубликован код программы и часть оригинальных PNG. Чтобы добавить остальные изображения без ухудшения качества:

1. Получи локальную копию репозитория и сохрани оригинальный архив `BossStudio_4_9_SYNC_OBS_3000.zip` на компьютере.
2. Запусти из папки репозитория:
   `python program/tools/restore_assets_from_zip.py "C:\путь\BossStudio_4_9_SYNC_OBS_3000.zip"`
3. Скрипт сверит SHA-256 всех 16 PNG (14 спрайтов и 2 предпросмотра), восстановит только отсутствующие файлы и соберёт точный `program/assets-embedded.js`.
4. Посмотри `git status`, затем выполни `git add program/assets "ПРЕДПРОСМОТР.png" "ПРЕДПРОСМОТР_РЕДАКТОРА.png"`, `git commit -m "Restore original Boss Studio sprites"` и `git push`.

**Не добавляй** в GitHub пароли, токены, локальные профили и очереди наград. `assets-embedded.js` автоматически восстанавливается из PNG, поэтому в GitHub его публиковать необязательно.

Скрипт не удаляет существующие файлы и отказывается переписывать изображение, если его контрольная сумма не совпадает с оригиналом.
