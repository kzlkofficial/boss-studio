# Boss Studio

Редактор боссов для Twitch и OBS с трофеями, страницей зрителя и ручной очередью выдачи мемкоинов MemeAlerts.

Текущая версия: Boss Studio 4.9. Исходники находятся в `program/`, инструкция запуска — `program/README_RU.md`.

## Профиль зрителя

Зритель подтверждает Twitch ID одноразовой командой в чате, видит личные трофеи и отправляет заявку с ником MemeAlerts после сбора коллекции. Стример выдаёт мемкоины вручную на MemeAlerts и отмечает заявку закрытой в локальном интерфейсе.

GitHub хранит код проекта. Живые профили, очередь заявок, токены и пароли не публикуются в репозитории. Для публичной страницы зрителя необходим сервер Boss Studio с HTTPS-доступом; статическая страница сама по себе не хранит защищённые данные.

## Дозагрузка оригинальных PNG

Смотри [пошаговую инструкцию](IMPORT_ASSETS_RU.md) и `program/tools/restore_assets_from_zip.py`. Скрипт проверяет контрольные суммы из оригинального ZIP и генерирует `assets-embedded.js` без изменения картинки.
